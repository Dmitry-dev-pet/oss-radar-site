Как мы это собираем

Публичные сведения получены через GitHub Search API и проверены по месяцам создания. Сбор выполнялся на собственном Mac M4, без коммерческих скраперов и модели, придумывающей названия. Каталог показывает только сохранённые результаты.

Редакторский обзор октября основан на документации авторов и отдельно отмечает внешние сервисы, ограничения лицензий и отсутствие независимых тестов.

  • Месяц: дата создания репозитория, не дата релиза.
  • Звёзды: общее число на дату снимка, не скорость роста.
  • Лицензия: декларация GitHub, не правовой аудит.
  • Тематика: автоматическая рубрика по описанию, возможны ошибки.
  • Покрытие: до 200 проектов на диапазон звёзд в месяц, середина диапазона иногда пропущена.
