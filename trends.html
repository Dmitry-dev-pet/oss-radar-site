Что растёт на GitHub?

Готовые публичные подборки и история звёзд через официальный API GitHub. Мы не выдаём старый каталог за живой рейтинг и не собираем заново историю тысяч репозиториев.

Суть: GitHub Trending Today публикует собственную выборку из GitHub Trending, а OSS Insight — альтернативную подборку. Они не охватывают все репозитории и используют разные методики. GitHub Pages импортирует готовый JSON GitHub Trending Today при публикации, чтобы не зависеть от браузерных ограничений CORS. Ошибка импорта не заменяется придуманными цифрами.

Официальный источник

История звёзд любого репозитория

GitHub возвращает недельные корзины с разбивкой по дням. Не нужен сервер, база, токен или семь дней предварительных наблюдений.

Укажите проект из каталога или введите owner/repo.

Источник: GitHub REST — Get repository star history. Данные отражают созданные звёзды (не чистое изменение общего счётчика) и имеют свои календарные границы. Возможны ограничения частоты запросов.
